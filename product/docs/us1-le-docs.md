## US-26 · Mengunggah dokumen ke brankas
Status: **Dibangun (simulasi)**

- Di pratinjau, berkas tidak benar-benar diunggah.

## US-27 · Menemukan dan mengunduh dokumen
Status: **Dibangun**

Sebagai member, saya ingin mencari dan mengunduh dokumen, agar saya bisa memakainya kapan saja.
- Pencarian dokumen, filter kategori, dan tombol unduh per dokumen.

## US-28 · Mendapat pengingat masa berlaku
Status: **Dibangun**

Sebagai member, saya ingin diberi tahu sebelum dokumen kedaluwarsa, agar saya sempat memperpanjang.
- Label status per dokumen (valid atau segera berakhir) dan notifikasi seperti "Employment contract ends in 58 days".

## US-29 · Membagikan dokumen secara aman
Status: **Dibangun**

Sebagai member, saya ingin membagikan dokumen ke advokat atau notaris hanya bila saya mau, agar data saya tetap dalam kendali saya.
- Tombol bagikan per dokumen dengan penerima dan tanggal berakhir.
- Konfirmasi "Shared. You can revoke it in Privacy." Akses bisa dicabut di menu Privacy.
